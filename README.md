# StegoLab

**Image-Based Data Hiding Using LSB Steganography**

StegoLab is an educational web application that demonstrates Least Significant Bit (LSB) image steganography for hiding and extracting text messages inside digital images.

## Objectives
- Implement LSB-based data hiding and extraction.
- Compare 1-bit, 2-bit, and 3-bit embedding methods.
- Evaluate image quality using Peak Signal-to-Noise Ratio (PSNR).
- Measure embedding capacity and extraction accuracy.

## Technology Stack
- Frontend: React, JSX, CSS
- Backend: Python, FastAPI
- Image processing: Pillow, NumPy
